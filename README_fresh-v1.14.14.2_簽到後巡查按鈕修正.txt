fresh-v1.14.14.2｜上班簽到後巡查按鈕無法啟用修正

問題原因
========
特殊假日本身不會停用巡查按鈕。

巡查按鈕是否啟用是依：
1. 有有效班表
2. 已找到「上班簽到」
3. 尚未找到「下班簽退」

舊版上班簽到成功後，首頁會再透過 dutyRecords 重新找簽到紀錄。
dutyRecords 嚴格只接受勤務開始～勤務結束之間的紀錄。

因此例如：
白班 06:00–18:00
05:55 先完成上班簽到

結果會變成：
- 簽到 API：成功
- Google Sheet：有「上班簽到」
- Dashboard：05:55 小於 06:00，被排除
- 前端 clockedIn 又變 false
- 「定點巡查」按鈕持續灰色

另外，若巡查進度或特殊勤務資料某一段讀取出錯，
舊版 Dashboard 也可能整體失敗，使前端把 clockedIn 重設 false。

本版修正
========
1. 上下班狀態改為獨立判定，不依賴巡查紀錄時段過濾。
2. 上班簽到只要已成功寫入該勤務日，就能被 Dashboard 認出。
3. 跨日晚班的次日下班簽退也能正確辨識。
4. Dashboard 的勤務紀錄、巡查進度、特殊勤務改為分段容錯。
5. 即使巡查進度或特殊勤務某段暫時讀取失敗，
   已完成上班簽到也不會被判回「尚未上班」。
6. 10/9 是否列為假日仍只影響假日巡查免巡規則，不影響簽到狀態。

保留
====
- 每日一次登入
- 上下班 GPS
- 指定人員支援
- 整班巡查不強制
- 黃／金色不用打卡進度
- 代班
- GPS 預熱
- 快速 Dashboard
